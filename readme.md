# LiteMC

A lightweight Minecraft Java Edition launcher with a clean interface and everything you need to manage your game.

## Features

- **Offline and Microsoft accounts** — choose an offline nickname or sign in with your Microsoft account.
- **Game and loader installation** — install Minecraft with Forge, Fabric, NeoForge, or compatible OptiFine builds.
- **Java management** — find an existing Java installation or download a suitable runtime.
- **Mods and shaders** — discover and install compatible content.
- **Personalization** — choose from five themes and manage your skin.
- **Reliable downloads** — resume interrupted downloads and verify file integrity.

## Downloads
